# Python Practice · Parts 1 to 14

This repository contains my practice work for the Python Programming MOOC, Parts 1 through 14.

I worked through each part of the course and saved my solutions here as I went. The folders are numbered by part, and each file inside is an exercise from that part.

The purpose of this repository is simple: to keep a record of my Python practice and to show the progress I made from the first part to the fourteenth. There is nothing extra here, just the exercises I completed while learning.

If you are learning Python yourself, you are welcome to look through the files. These are my own answers, so they may not be the only or the best way to solve each exercise, but they are what I wrote while working through the course.
